# AI Recipe Book - Style Guide

## Design Philosophy & Visual Language

Our design system emphasizes modern minimalism with a focus on clarity and usability. We use Material-UI (MUI) as our component foundation with a clean, content-first approach. The visual aesthetic prioritizes generous white space, subtle shadows (0 2px 8px rgba(0,0,0,0.1) for cards, 0 4px 12px for elevated elements), and rounded corners (borderRadius: 2 = 16px for cards/containers, 8px for icon boxes). Typography follows a clear hierarchy with primary headings at h3 (2rem mobile, 2.5rem desktop) and h5 (1.25rem mobile, 1.5rem desktop) for section headers, always using fontWeight 600 for emphasis. Body text uses standard MUI sizes with text.secondary for supporting content and text.primary for emphasis. Color usage is intentional and restrained: primary blue for CTAs and active states, grey.100 backgrounds for informational icon boxes, primary.50 (light blue) for action-oriented icon boxes, and strict adherence to MUI's text.primary, text.secondary, and text.disabled for all text to ensure consistent contrast and readability.

## Layout, Spacing & Interaction Patterns

Layouts use consistent horizontal padding (px: 3 = 24px) across all pages, aligning navigation, sub-navigation, and content to create visual coherence. Maximum content widths prevent excessive line lengths (800px for text-heavy content, 1200px for recipe pages, no maxWidth for full-width grids). Spacing follows MUI's 8px grid system: mb: 1 (8px) for tight grouping, mb: 2 (16px) between related elements, mb: 3 (24px) for section separation, mb: 4-6 (32-48px) for major sections. Responsive breakpoints use MUI's system (xs < 600px, sm ≥ 600px, md ≥ 900px, lg ≥ 1200px, xl ≥ 1536px) with mobile-first design where elements stack at smaller sizes and expand side-by-side on desktop. Interactive elements follow clear patterns: Floating Action Buttons (FAB) are positioned fixed at bottom: 24px, right: 24px with consistent shadows; IconButtons use 40x40px size with 1px borders (divider for default, primary.main for active); hover states add action.hover background and darker borders; transitions use 0.3s ease for smooth state changes. Component patterns include RecipeCard with 16:9 aspect ratio images, left-aligned recipe page headers with centered titles and photos (900px max), and side-by-side desktop chat (400px fixed width, 24px spacing from content). Empty states use instructional layouts with icon boxes (40x40px), clear headings, descriptive body text, and prominent CTAs. All interactive elements include proper aria-labels for accessibility, and we maintain semantic HTML structure throughout.
